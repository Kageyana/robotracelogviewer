# 空のメタ情報行を textscan に渡すと読み込みが失敗する

## 要約

空のメタ情報行を許容するCSVで、textscanへの空文字入力がエラーになった。空行を直接空のstring列として扱うことで修正し、MATLAB R2023bで確認した。

## 発生した状況

- タスク: src/test.txtのヘッダ読み込みを先頭2行に限定し、メタ情報を文字列化する。
- 実行環境: Windows / MATLAB R2023b。
- 前提条件: 1行目は空のメタ情報、2行目は有効な列名、3行目以降は数値データ。

## 何を試したか

1. fgetlで得たメタ情報行を、空行の場合もtextscanへ渡した。
2. 検証用CSVを読み込んだ。

## 結果・エラー

```
MATLAB:textscan:NoInput
```

## 原因

空文字へのtextscan呼び出しが入力なしとして扱われる。空のメタ情報行と、ファイル末尾により行自体が存在しない状態を分ける必要がある。

## 解決・回避策

readLogHeadersで行の存在を確認し、空のメタ情報はstrings(0,1)にする。空の列名行は明示的に不正ヘッダとして拒否する。

## 今後の予防策

ヘッダパーサーを変更するときは、空メタ情報・空列名・1行だけのファイルを別のケースとして確認する。空メタ情報では読込成功と表示クリア、空列名と行不足では読込失敗と既存データ保持、終了時のファイル解放を確認する。

## 確認方法

MATLAB R2023bの検証で、実ログ5,593行、数値/NaN/空欄/引用符付きカンマ/日本語のメタ情報、BOM、空メタ情報、20,000項目、末尾カンマ、不正列名、既存データ保持、ファイル解放がすべて成功。プロセス終了コード0。
